# 本草冥想 - 文字檔轉語音工具

跟《草本夜話》Podcast 一樣的做法：**改文字檔 → 雙擊 .bat → 出音檔**。
語音在你電腦上用 edge-tts 生成（沙盒連不到微軟伺服器，所以這步一定要在本機跑）。

## 資料夾

```
冥想音檔工具/
├─ 腳本/            ← 放要轉的文字檔（*.txt），一支藥一個檔
├─ 成品/            ← 轉好的 mp3 會出現在這裡
├─ 背景音樂/        ← 放你要用的背景音樂（第一個 mp3 會自動套用）
├─ 試聽/            ← 試聽聲音的輸出
├─ 轉語音.bat       ← 雙擊：只轉還沒有成品的腳本
├─ 全部重轉.bat     ← 雙擊：全部重轉、覆蓋舊成品
├─ 試聽聲音.bat     ← 雙擊：產生一小段試聽，確認聲音／語速
├─ run_tts.py       ← 主程式（聲音、語速、背景音量都在檔案上方設定）
└─ preview.py       ← 試聽用
```

## 怎麼用

1. **放背景音樂**：把想用的音樂丟進「背景音樂」資料夾。沒放的話會只輸出純人聲。
2. **雙擊「轉語音.bat」**，等視窗顯示「全部完成」。
3. mp3 會出現在「成品」資料夾。滿意後再把它們複製到 `public/meditations/` 覆蓋舊檔（檔名要一致，例：`meditation_01_renshen.mp3`）。

> 想換聲音或語速：打開「冥想轉語音.py」最上面的設定區改 `VOICE` / `RATE` / `BGM_VOLUME` 即可。
> 目前聲音＝`zh-TW-HsiaoChenNeural`（曉臻，與 Podcast 同一個），語速 `-20%`。

## 腳本 txt 寫法

一行一句，句尾標停頓秒數（可小數），有兩種標記：

- `[停N]`：**固定**小停頓，不隨長度改變（句與句之間的呼吸空檔）。
- `[靜N]`：**可延展**的深度留白。做長版本（5/10 分）時，工具會把這些 `[靜]` 撐長來湊足總長，N 是它的最短秒數。

```
歡迎來到酸棗仁觀想冥想。[停2]
輕輕閉上眼睛，讓呼吸自然流動。[停4]
[靜10]
慢慢地，準備好的時候，睜開眼睛。[停3]
```

> 一支腳本至少放 3～4 個 `[靜]` 點（通常在身體掃描後、中段、結尾前），長版本才有地方「變長」。沒有 `[靜]` 的腳本做長版時無法變長。

## 多長度（3/5/10/15）

雙擊 `轉語音.bat` 預設會產出 **5 分和 10 分**兩個版本，檔名自動加後綴：
`meditation_40_suanzaoren_05m.mp3`、`meditation_40_suanzaoren_10m.mp3`。

- 想改長度：在終端機跑 `py run_tts.py --minutes 5,10`（或 `3,5,10,15`）。
- 想只要原始單一長度：`py run_tts.py --minutes 0`。
- app 端已接好：某味藥有幾分鐘版本，就在 `src/data/meditations.js` 的 `AUDIO_LENGTHS` 登記（目前酸棗仁 = `21: [5, 10]`）。播放時選 5 分或 10 分就會播對應檔，沒有的長度退回原檔。

## 需要的環境

- Python 3（你電腦已有）
- edge-tts（第一次跑會自動安裝）
- ffmpeg（需在 PATH；你電腦已有）

## 目前狀態：全部 54 味都已備好腳本

「腳本」資料夾裡有 54 支腳本，每支都用該藥材的實際藥性、視覺、氣味、功效寫成，並加好 4 個 `[靜]` 深度留白（支援長度）。安神助眠類藥材會用「入睡」的收尾。

雙擊 `轉語音.bat` → 會把 54 味 × 5 分／10 分＝ **108 支**全部轉出到「成品」。

> 全部轉完需要一段時間（大概 20～40 分鐘，看網路）。中途關掉沒關係，再雙擊一次會自動略過已完成的、接著跑。

跑完後：把「成品」裡的 mp3 全部複製到 `public/meditations/`（覆蓋同名舊檔）→ app `npm run build` 重新部署。app 已設定所有藥材都有 5／10 分版本，選哪個就播哪個。
